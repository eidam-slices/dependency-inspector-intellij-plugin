Detects outdated Gradle dependencies and plugins declared in version catalogs.

The inspection checks dependency versions against versions available in Maven Central and highlights declarations for which a newer stable version is available. ()

It supports dependencies declared with direct versions as well as shared versions referenced through version.ref. 


[versions]
ktor = "3.3.0"

[libraries]
ktor-server-core = { module = "io.ktor:ktor-server-core", version.ref = "ktor" }

Dependency Inspector resolves version information asynchronously and caches the result for the current project.
