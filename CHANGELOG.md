# Version Inspector Changelog

## [0.1.0] - 2026-09-13

### Added

- Gradle Version Catalog support
- Maven Central version resolution
- Inspection for newer dependency versions
- Quick fixes for updating outdated versions
- Support for direct versions `version` and references `version.ref`

## [0.1.1] - 2026-09-13

### Added
- Inspections and quick-fixes now displays group and artifact of dependency on repository
